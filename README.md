# Kisan Remote Flow — Releases

Distribution channel of **Kisan Remote Flow**, a remote desktop application by Kisan Electronics based on [RustDesk](https://github.com/rustdesk/rustdesk) OSS.

Each release contains:

| File | Purpose |
|---|---|
| `KisanRemoteFlow-<version>-x86_64.exe` | Windows x64 package (run to start, `--install` to install) |
| `krf-update.signed` | Update manifest signed with Ed25519; installed clients verify it before updating |
| `kisan-remote-flow-<version>-src.tar.gz` | Corresponding source code of that release (AGPL-3.0) |
